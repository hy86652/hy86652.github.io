个人项目：一个算法交易系统，我用 Claude Code 来做原型和迭代。

AI 让我在策略逻辑上推进得很快，包括分析市场数据、寻找信号规律、对假设做压力测试。我给自己定的规则是：任何逻辑都要先用真实市场行为验证过，才能提交。金融数据里充满边界情况，而这恰恰是 AI 生成的代码最容易"自信地出错"的地方，所以必要时我会推翻它的输出。

**技术栈：** Python、Claude Code
