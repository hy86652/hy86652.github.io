A website where university students can list their rooms, search for housing on a map, and arrange swaps. It started as a response to campus housing shortages.

What exists so far is the front end: 16 static pages in plain HTML, CSS, and JavaScript that cover the whole flow, from the home page, search, listings, and room details to sharing a room, chat, a personal dashboard, sign-up and login, reviews, help and FAQ, and a 404 page. Search and room details use the Google Maps JavaScript API for map-based browsing; an earlier version used Mapbox.

The plan was to make the static site feel like a real product first, so that a back end could later be plugged in without redoing the UI. The back end (Node.js and Express) is laid out in the repository's design notes but not built yet.

The project won **2nd place at the UC Davis Big Bang! Business Competition (2025)**. The judges recognized both its technical feasibility and its market potential.

**Stack:** HTML, CSS, JavaScript, Google Maps JavaScript API, Netlify
